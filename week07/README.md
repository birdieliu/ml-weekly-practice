## 实践一：五步 RNN

### 数据与运行

复用 `../week06/data/ETTh1.csv`，取前六条 OT。
前五条作为输入，第六条作为目标。
统一使用 `z[k] = (u[k] - u[1]) / 10` 变换。

在仓库根目录运行：

python week07/rnn_demo.py

状态与梯度记录保存到 `week07/results/rnn_trace.csv`。

### 代码与接口

`rnn_demo.py` 负责小 RNN 的前向、反向、顺序对照和记录保存。
导入文件时不自动运行实验。

`forward_sequence` 接收输入、读取顺序、共享参数及来源信息，
返回预测张量和逐步记录。
预测张量保留计算关系，供损失与反向传播使用；
记录转换为普通数值，供显示与保存使用。
两组顺序复用相同的状态更新逻辑，每次从零状态开始。

### 原顺序结果

- 预测值：-0.396435
- 目标值：-0.935700
- 平方误差损失：0.290806
- wx 梯度：-0.61694348
- wh 梯度：-0.29319879
- b 梯度：0.92631000

以上预测、目标和损失均处于演示变换后的尺度。

### 观察

五步使用同一组 wx、wh、b；每一步变化的是输入和隐藏状态。
末步隐藏状态通过固定变换 `0.8 * h + 0.1` 生成预测。

虽然只在末端计算一次损失，五个输入都有非零梯度，
说明早期输入通过状态链影响末端损失。
本例中较早输入的梯度较小，但五步记录不能证明长序列训练
一定发生梯度消失。本实践没有更新参数。

顺序对照使用相同参数，预测为 -0.368081。
两组从第二步开始产生不同状态。
第五步输入相同，但上一状态分别为 -0.421819 和 -0.310408，
因此最终状态与预测不同。
对照是人为调整输入顺序，不代表设备真实运行过程。
## 实践二：LSTM 下一小时油温预测

### 数据与标准化

复用 ETTh1 前14,400条小时记录，只使用 OT。
使用目标之前24个真实观测预测下一小时，先构造窗口，再按目标时间划分。

训练、验证、测试样本数分别为8616、2880、2880。
每小时获得真实观测后再预测下一小时，验证和测试期间不更新模型参数。

使用原始训练时段的 OT 计算统计量，每个时刻只计一次：

- 均值：17.12826170
- 总体标准差：9.17649102，使用 `ddof=0`

输入和目标均使用训练统计量标准化。预测还原至原始油温尺度后计算 MAE、RMSE。

### 模型与形状

模型为单层、单向 LSTM，`input_size=1`、`batch_first=True`，
`dropout=0`、`proj_size=0`。取最后一个时间步的隐藏表示，
经过无激活函数的线性层预测下一小时。

使用4条实际训练样本检查：

| 内容 | 隐藏维数16 | 隐藏维数32 |
|---|---|---|
| 输入 | (4,24,1) | (4,24,1) |
| 每步隐藏输出 output | (4,24,16) | (4,24,32) |
| 最终隐藏状态 h_n | (1,4,16) | (1,4,32) |
| 最终细胞状态 c_n | (1,4,16) | (1,4,32) |
| 末步隐藏表示 | (4,16) | (4,32) |
| 预测 | (4,1) | (4,1) |
| 模型参数总数 | 1233 | 4513 |

`output[:, -1, :]` 选出末步隐藏表示。
在本次单层、单向设置下，已核对它与 `h_n[0]` 一致。
`h_n` 和 `c_n` 最前面的轴表示层与方向的组合。

细胞状态通过遗忘门保留旧内容，通过输入门写入候选内容；
隐藏状态由细胞状态经过 tanh 和输出门形成。
两者形状相同，但计算职责不同。

每个窗口使用零初始隐藏状态和细胞状态，不跨批次传递状态。
重置状态不会重新初始化模型权重。
训练样本可以打乱，但每条窗口内部保持时间顺序。

### 训练与选择

使用 CPU、float32、Adam，学习率0.001、weight_decay=0，
其余优化器参数默认。损失为标准化目标上的 MSE。
batch_size=128、drop_last=False、num_workers=0。

两种宽度各训练40轮。每组创建模型前设置随机种子42，
每组训练 DataLoader 使用独立的种子42生成器，只打乱训练样本。

每轮结束后重新评价完整训练、验证集。
按验证 MSE 保存独立的最佳参数副本，完全同分时保留较早轮次。

| 隐藏维数 | 最佳轮次 | 验证 RMSE（原始尺度） |
|---|---:|---:|
| 16 | 38 | 0.914489 |
| 32 | 39 | 0.914154 |

按验证 RMSE 选定隐藏维数32。
完全同分时选择16；本次未发生同分。
选择固定后，只评价选定 LSTM 的测试集，不合并训练验证集重训。

### 基线与结果

复用 week06/results/predictions.csv 中的 last_value 和 lag_linear。
两种基线使用相同的24小时历史范围、目标和时间划分。
lag_linear 沿用上周仅在训练集拟合的按输入列标准化与线性回归管道，
不使用 LSTM 的标准化统计量。

程序逐条核对了目标下标、时间和真实油温，检查无重复或遗漏，
并从逐行预测重新计算指标。

| 方法 | 验证 MAE | 验证 RMSE | 测试 MAE | 测试 RMSE |
|---|---:|---:|---:|---:|
| last_value | 0.608238 | 0.925271 | 0.420152 | 0.592978 |
| lag_linear | 0.598923 | 0.910183 | 0.422645 | 0.584538 |
| lstm_h16 | 0.600201 | 0.914489 | 未评价 | 未评价 |
| lstm_h32 | 0.597546 | 0.914154 | 0.448564 | 0.609383 |

两种 LSTM 的验证表现接近。选定 LSTM 的验证 MAE 略低于线性回归，
但验证 RMSE 略高；测试集上两项指标均不及两种基线。
因此不能认为本次 LSTM 整体优于基线，也不根据测试结果继续调参。

损失曲线前期下降较快，后期改善较小并有波动，
没有明显的验证损失持续上升趋势。
训练误差高于验证误差，不能单凭这一点判断不存在过拟合，
两个时段的数据波动程度也可能不同。

验证首周图中三种方法整体接近，在一些骤降和回升处跟随转折较慢，
LSTM 没有明显消除这一现象。局部图形与完整验证指标需要结合分析。

模型结构允许早期输入影响结果，但不能仅凭成绩判断模型学好了长期依赖。
预测对早期输入敏感，也不等于这些信息确实改善了预测。

### 一个具体预测样本

第一条验证目标为2017-06-26 00:00，原始下标8640。
输入是下标8616至8639，即2017-06-25 00:00至23:00的24个真实油温；
目标油温为20.962999。

输入使用训练均值和标准差变换，形成 (1,24,1) 张量。
选定的32维 LSTM 从零状态开始，逐步更新细胞状态和隐藏状态。
取第24步隐藏表示，经线性层得到标准化预测，
再通过 `预测值 * sigma + mu` 还原油温。
该表示是通过预测损失学习的，各分量不直接对应某一个小时。

### 主要组件与接口

| 文件 | 职责 |
|---|---|
| sequence_data.py | 复用上周数据检查、窗口和划分，完成本周标准化 |
| models.py | 定义 LSTM 与线性预测层 |
| check_lstm.py | 检查实际样本的张量形状和参数数量 |
| training.py | 训练单个配置、完整集评价、恢复最佳参数 |
| evaluation.py | 分批预测、逆变换、生成逐行预测表 |
| run_lstm.py | 组织两种配置训练、验证选择和选定模型保存 |
| summarize_results.py | 合并基线、核对预测、计算指标 |
| reporting.py | 读取结果并绘制两张图 |

`prepare_data` 返回按集合组织的数据与 mu、sigma，
将数据处理和模型训练分开，并保留目标下标、时间与原始真实值，
便于核对预测和计算原始尺度指标。

`fit_one_model` 返回恢复最佳参数的模型、训练记录、最佳轮次和验证 MSE，
使运行入口能够统一组织配置比较与结果保存。

### 运行方式

在仓库根目录、已安装依赖的 Python 环境中依次运行：

```bash
python week07/rnn_demo.py
python week07/sequence_data.py
python week07/check_lstm.py
python week07/run_lstm.py
python week07/summarize_results.py
python week07/reporting.py
```

run_lstm.py 会重新训练并覆盖 LSTM 记录；
之后应依次运行汇总与绘图脚本，重新生成完整结果。

数据复用 week06/data/ETTh1.csv，不重复保存。
基线预测复用 week06/results/predictions.csv。

### 输出

results/ 中保存：

- rnn_trace.csv：两组各五步的状态记录，原顺序包含输入梯度。
- history.csv：两组各40轮，MSE为标准化尺度。
- metrics.csv：11行模型与集合指标，MAE、RMSE为原始尺度。
- predictions.csv：54,624行对齐预测，真实值与预测值均为原始尺度。
- loss_curves.png：两种宽度的训练、验证曲线与最佳轮次。
- validation_predictions.png：验证首周真实值、两种基线与选定 LSTM。
- chosen_lstm.pt：选定模型的最佳参数、隐藏维数、最佳轮次与标准化统计量。
